# Agent Collaboration

## Responsibilities

- Main agent: requirements, plan, integration, and verification.
- Architect: contracts and important technical decisions.
- Frontend: UI implementation and design-system compliance.
- Backend: APIs, business logic, and server-side authorization.
- Database: data model, relationships, and indexes.
- QA: tests, edge cases, and regressions.

These roles are responsibilities, not mandatory autonomous agents.

## Conventions

- One owner controls a file or integration.
- Exchange interfaces before parallel implementation.
- Use subagents only when the selected tool supports safe ownership.
- Otherwise use sequential execution.
- Read project memory before work and update it after meaningful changes.
